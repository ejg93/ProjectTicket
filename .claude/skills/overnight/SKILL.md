# 밤샘

**번들 여럿을 사용자 없이 머지까지 친다.** 번들 하나를 치는 법은 `CLAUDE.md` 「번들 모드」와 `/wrapup` 이 든다 — 이 스킬은 그 앞뒤만 든다: 자기 전에 받을 것, 밤에 세우는 원인, 멈추는 자리.
첫 실측은 2026-09-26 밤(번들 1·2a·3, `PROGRESS.md` 이력).

## 자기 전에 — 결정을 한 번에 받는다

플랜 세션(Fable, plan mode)이 아래를 `AskUserQuestion` 으로 한 번에 묻고 플랜 파일에 답을 적는다. 실행 중에는 안 묻는다.

| 무엇 | 왜 지금 |
|---|---|
| 열린 PR 처리 — 실행이 머지하고 새 가지 / 같은 가지에 쌓기 | 번들 하나 = PR 하나가 지켜지나 |
| 번들 끝 PR 머지 위임 — CI 초록 + 리뷰 봇 코멘트 처분 뒤 `gh pr merge N --merge` | 머지를 막는 훅·설정이 없는지 먼저 확인한다. 가지 보호의 필수 검사만 남는다 |
| 번들 범위 — 설계(결정·번호 절차·실패 사다리)가 이미 적힌 행만 | 설치가 필요한 행·재설계가 필요한 행은 뺀다 |
| 설계 없는 행 — (가)/(나) 로 묻고 답을 설계 형식 행으로 적는다 | 그 행이 밤에 서지 않게. 첫 커밋이 `PLAN.md` 에 옮긴다 |
| 실행 모델 | 규칙은 Opus(`PLAN.md` 「누가 치나」). 승인 뒤 사용자가 `/model` 로 바꾼다 |
| 전원 — 플러그·뚜껑 | 노트북은 배터리에서 몇 분이면 절전이다(`powercfg /q SCHEME_CURRENT SUB_SLEEP STANDBYIDLE`) |

## 밤에 세우는 것 — 순서대로 값이 크다

| 원인 | 막는 법 |
|---|---|
| 노트북 절전 | 위 결정. AC 는 절전 없음·배터리는 3분이었다 |
| Docker Desktop 꺼짐 | `scripts/docker-up.sh` 가 켜고 3분까지 기다린다 — `verify.sh`·`gate-probe.sh` 가 컨테이너 앞에서 부른다 |
| 토큰 창 소진 → 세션 정지(자동 재개 없음) | 청크 = 커밋이라 선 자리는 깨끗. 아침에 `번들 해` 가 「현재 상태」·이력 마지막 줄에서 잇는다. 머지 안 된 PR 은 사용자가 |
| 컨텍스트 압축 | 재개 프로토콜이 행마다 `PLAN.md` 를 다시 읽는다 — 압축돼도 같은 절차 |
| CI 빨강 | 고치기 둘(커밋·push·`gh pr checks --watch`)까지, 그래도면 PR 열어 둔 채 멈추고 보고 |
| 바깥 fetch 실패(GitHub·npm·코퍼스) | 그 행의 실패 사다리, 없으면 「정한 것(계획 밖)」으로 건너뛰고 이력에 |
| 계획 밖 결정 폭주 | 행당 둘, 셋째면 `wip/<id>` 곁가지 + 다음 행 |

## 번들 사이 — 머지까지

`/wrapup` 을 그대로 하고 뒤에 셋을 더한다: `gh pr checks --watch` → 초록이고 `review` 잡 코멘트 0(있으면 처분) → `gh pr merge N --merge` → `git checkout main && git pull` → 다음 가지(`work/<날짜>`, `-b`, `-c`).
독립 리뷰는 빼지 않는다 — 번들 0 에서 지적 14(오탐 0), 그중 하나가 원본 `node_modules` 를 지울 수 있던 결함이었다.

## 멈춤 — 끝 보고

마지막 번들의 `/wrapup` 끝 보고에 밤 전체를 모은다: 계획 밖 결정 전부 · WIP 행과 이유 · 신규 행((가)/(나)) · 사람이 할 것(설치·재설계).
「현재 상태」의 「다음 첫 손」이 아침의 첫 줄이다.

**아침에 보는 것**: `main` 의 마지막 커밋 · `PROGRESS.md` 「현재 상태」 · `gh pr list` · `git branch --list 'wip/*'`.
