# ADR 0009 — 대기열은 Redis ZSET + 예산 창 그대로다

2026-10-21. 청크 50. 근거는 `load-4`(49, 줄 1만 → 선점)와 `load-3` 「35c-재」. 둘째 구현은 없다 — **글로 견준다**(사용자 결정 2026-10-18).

## 맥락

ADR 0001 이 Kafka 대기열을 한 줄(「순서·입장 제어에 ZSET 이 맞고 참조 구현 전부가 이 방식」)로 버렸고 ADR 0007 이 되풀이했다. 비교 문서가 없었다.
지금 구조는 둘이 겹친 것이다 — **줄**(ZSET `queue:{id}`, 순서)과 **속도**(HASH `queue:{id}:admit_window` 의 `start`·`used`, Redis `TIME`, `35f`).
뒤의 것이 토큰 버킷이다 — 창(5초)마다 예산 100 을 채우고 입장이 꺼내 쓴다.

실측(`load-4`, compose 셋 · 한 노트북):

| 무엇 | 값 |
|---|---|
| 입장 속도 | 줄이 R(20명/초) 아래로 붙는다 — 등식 비율(대기 ÷ 순번/R) p50 1.01 · p95 1.12 |
| 「내 순번」 폴링 p95 | 104ms(1만 × 2초, 평균 1,472 rps, 5xx 0) |
| 순번 정확도 | 비율 p50 1.01 — 화면의 `eta = rank / R` 이 실제 대기와 맞는다 |
| Redis 크기 | 줄 1만에 `DBSIZE` 약 3만(세션 1만 포함, 「35c-재」) |

## 저울질한 것

| | **Redis ZSET + 예산 창** | Kafka 토픽 대기열 | 토큰 버킷 단독 |
|---|---|---|---|
| 처리량 | 폴링이 `ZRANK` 한 번 — 위 실측 | 진입은 produce 한 번으로 싸다. 폴링은 아래 순번 저장소가 든다 | 가장 싸다 — 상태가 카운터 하나 |
| 「내 순번」을 답하나 | **답한다** — `ZRANK` 가 O(log N) | **못 한다** — 파티션 안 순서만 있고 오프셋으로 「내 앞에 몇 명」을 물을 길이 없다. 순번용 저장소가 하나 더 든다 | **못 한다** — 줄이 없다. 늦게 온 사람이 운 좋게 먼저 들어간다 |
| 장애 시 | Redis 가 죽으면 관문이 닫힌다(503 `queue-unavailable`) — 아무도 못 사지만 DB 는 안전 | 브로커가 죽으면 진입이 멈춘다. 순번 저장소와 둘 중 하나만 죽는 경우가 생긴다 | 카운터가 날아가면 한 창만큼 더 들어온다 |
| R 제어 | 예산 창이 Lua 안에서 지킨다 — 대수와 무관(`35f`) | 소비 속도로 조절 — 소비자 수를 따라 R 이 흔들린다 | 그 자체가 R 이다 |
| 다중 인스턴스 일관성 | Lua 원자 — 같은 사람을 두 번 안 들인다 | 소비자 그룹 재조정 때 파티션이 옮겨 가며 입장 순서가 흔들린다 | 원자 증감이면 된다 |
| 재진입 공정성 | `ZADD NX` — 새로고침해도 자리 유지 | 재진입이 새 메시지라 줄 끝으로 간다. 막으려면 계정별 상태가 또 든다 | 줄이 없어 개념이 없다 |
| 운영 비용 | Redis 하나(세션과 같이 쓴다) | 토픽·파티션·소비자 그룹 + 순번 저장소 | 가장 작다 |

## 결정

- **지금 구조를 유지한다.** ZSET 이 줄, 예산 창이 속도다
- **토큰 버킷은 이미 속도 층으로 있다** — 예산 창이 그것이다. 단독으로 쓰면 순번이 없어져 「약 N분」 화면(`D17`)과 재진입 공정성을 잃는다
- **Kafka 대기열은 순번 저장소가 하나 더 든다** — 그러면 대기열이 Redis 를 안 버리고 브로커를 하나 더 얹는 꼴이다. Kafka 는 확정 뒤 사건(ADR 0007)에만 둔다(대전제 4)

## 결과

- ADR 0001 의 한 줄 근거가 이 표로 선다
- `queue-design.md`(`D12`) 의 자료구조 표에 `admit_window` 행이 생기고, 「지금 안 하는 것」에 이 ADR 이 걸린다
- **다시 볼 조건**: 줄이 Redis 한 대의 메모리를 압박할 때(지금 줄 1만에 키 약 3만) · 순번 없는 입장(추첨)으로 요구가 바뀔 때 — 추첨이면 순번이 필요 없어 토큰 버킷 단독이 다시 후보다
