# 문서 트리

| 경로 | 무엇이 들어 있나 | 누가 읽나 |
|---|---|---|
| `doc/reference/` | 여러 청크가 같이 참조하는 기준 문서(D 줄) | 그 결정에 걸린 청크를 잡은 사람 |
| `doc/adr/` | 한 번 정하고 되돌릴 때 근거가 필요한 결정 | 그 결정을 뒤집으려는 사람 |
| `doc/notes/` | 읽을거리·측정 기록. 청크 실행 때 안 본다 | 읽고 싶은 사람 |
| `.claude/skills/` | 세션이 따르는 절차 | 트리거 단어를 받은 사람 |
| `PLAN.md` | 만들 대상과 청크 분할표 | 다음 청크를 고르는 사람 |
| `PROGRESS.md` | 청크별 완료·진행중 로그 | 세션을 재개하는 사람 |
| `README.md` | 띄우는 법 | 처음 받은 사람 |

## 기준 문서와 ADR 을 가르는 기준

**참조자가 몇인가.** 둘 이상이면 `doc/reference/`, 하나면 `doc/adr/`.
한 청크에서만 쓰는 결정이라도 나중에 「왜 이렇게 했나」를 물을 것 같으면 ADR 로 남긴다.

## 기준 문서 안에 안 쓰는 것

- 지나간 작업 이력 — `PROGRESS.md` 와 `git log` 가 답한다. 제목에 날짜가 있으면 `doc-lint.sh` 가 빨갛다
- API 레퍼런스 — 버전이 올라가면 낡는다. 공식 문서 링크와 「기억으로 쓰면 틀리는 자리」만(`stack.md`)
