# 용어집

코드·문서·화면이 같은 말을 쓰게 하는 표. 영문은 식별자, 한글은 화면·문서.

| 한글 | 영문(식별자) | 뜻 | 안 쓰는 말 |
|---|---|---|---|
| 관객 | account / audience | 예매하는 사용자 | 고객, 유저 |
| 기획사 | organizer | 공연을 올리고 정산받는 주체 | 판매자, 셀러 |
| 공연장 | venue | 건물 | 극장 |
| 홀 | hall | 공연장 안의 공간. 좌석 배치 단위 | 관 |
| 좌석 | seat | 홀의 물리 좌석 | 자리 |
| 구역 | section | 좌석의 큰 묶음(A구역·1층) | 블록 |
| 열 | row | 구역 안의 줄 | |
| 등급 | seat_grade | VIP·R·S 등 가격 등급 | 클래스 |
| 공연 | event | 작품 단위 | 이벤트(화면에서 안 쓴다) |
| 회차 | performance | 공연의 특정 일시 | 세션, 스케줄 |
| 회차 좌석 | performance_seat | 회차별 좌석 상태 행 | |
| 선점 | hold | 결제 전 좌석을 잠시 잡음. `HELD` | 임시 예약, 락 |
| 선점 만료 | hold expiry | `held_until` 경과. 스윕이 해제 | 타임아웃 |
| 예매 | reservation | 관객이 좌석을 잡아 결제까지 가는 단위 | 예약, 주문 |
| 확정 | confirm | 결제 성공으로 `RESERVED` | 완료 |
| 취소 | cancel | 관객이 확정 예매를 무름 | 환불(돈 쪽 말) |
| 환불 | refund | 취소에 따른 금액 반환 | |
| 취소 수수료 | cancellation fee | 관람일 기준 구간별 공제 | 위약금 |
| 발권 | ticket issue | 확정 예매에 티켓 번호 발급 | 출력 |
| 티켓 | ticket | 좌석 하나의 입장권 | 표 |
| 대기열 | queue | 회차 오픈 때 입장 순서 | 대기실 |
| 순번 | rank | 대기열 안 위치 | |
| 입장 | admission | 대기열에서 활성으로 옮김 | |
| 활성 토큰 | admission token | 예매 API 를 부를 수 있는 증표. TTL | 세션 |
| 아웃박스 | outbox | 트랜잭션과 같이 커밋되는 이벤트 행 | |
| 정산 | settlement | 회차 종료 후 기획사 매출 집계 | 지급 |
